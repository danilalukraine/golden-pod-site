# Golden Pod — website

Static site for **golden-pod.com**, served via GitHub Pages.

- Homepage `index.html`; clean-URL pages under `pricing/`, `about/`, `samples/`, `methodology/`, `privacy/`, `terms/`, `legal/`, `api/`.
- Assets under `static/` (fonts, favicons, sample reports).
- `CNAME` binds the custom domain; `.nojekyll` disables Jekyll.
